# Analysis Output Summary

Parameters extracted from ETABS pushover analysis:
- Storey shear (base to roof)
- Overturning moment
- Storey displacement
- Storey drift
- Hinge state (IO/LS/CP) at each storey, per hazard level

All modelling iterations were evaluated against FEMA hinge 
performance criteria across SLE, DBE, and MCE hazard levels.
