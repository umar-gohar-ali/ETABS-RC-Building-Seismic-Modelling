# Plastic Hinge Length

Formula used (Priestley et al., 1996 / ATC-32):

lp = 0.08l + 0.15 * db * fy

Where:
- lp = plastic hinge length (in)
- l  = distance from critical section to point of contraflexure (in)
- db = rebar diameter (in)
- fy = rebar yield strength (ksi)

Alternative simplified expression used for cross-check:
lp = 0.5h (h = member depth)
